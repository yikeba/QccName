OSN 引导协议
说明（通俗版）The OSN bootstrap protocol,
in plain words

引导协议是一份 JSON 文件，写着 .osn / .osnsg 这两个账户名后缀的全部规则。它由 OSN 签名发布在 QCC 公链上，所有节点都按它运行，谁也不能私自修改。协议原文是给开发者看的；这一页用普通的话解释它说了什么。The bootstrap protocol is a JSON file holding every rule for the .osn / .osnsg account suffixes. OSN signed and published it on the QCC chain; every node runs by it and nobody can change it in private. The original is for developers; this page explains what it says in plain words.

规则一览The rules

下表是协议里每条规则的白话版本。Each rule of the protocol, in plain words.

规则Rule意思What it means
名字格式Name format名字.osn，名字 2–32 个字符，只能用小写字母、数字和 -，不能以 - 开头或结尾name.osn; the name is 2–32 characters of lowercase letters, digits and -, not starting or ending with -
谁能注册Who can register任何人都可以，用自己的钱包签名注册，并质押 1 QCC 作为门槛Anyone, by signing with their own wallet and pledging 1 QCC as the entry bar
注册 ≠ 能用Registered ≠ admitted注册了 .osn 名字，不代表能使用 OSN 的邮箱或内部系统。能不能用，由各系统的白名单决定Holding a .osn name does not grant OSN mail or internal systems. Each system's whitelist decides
一个地址一个名字One name per address同一个钱包地址在 .osn 下只能有一个名字（.osnsg 另算）One wallet address holds at most one .osn name (.osnsg counts separately)
不能改、不能转No edits, no transfers名字只能注册或删除；质押撤销后名字自动回收A name can only be registered or deleted; withdrawing the pledge reclaims it automatically
冷却期Cooldown名字删除或回收后 30 天内，任何人都不能重新注册，防止被人立刻抢走冒充For 30 days after deletion or reclaim, nobody can register the name, so it cannot be grabbed for impersonation
形近字Lookalikes0 视同 o、1 视同 l、rn 视同 m：已有 admin.osn，就不能再注册 adrnin.osn0 counts as o, 1 as l, rn as m: with admin.osn taken, adrnin.osn is refused
管理名（Reserved）Management names (Reserved)OSN 用发布者地址签名发布一张管理名表，表里的名字只对应 OSN 指定的地址，优先于任何注册OSN publishes a table of management names signed by the publisher; those names map only to the addresses OSN sets, above any registration
冻结Freezing发现可疑账户，OSN 把它写进管理名表并留空地址：原注册立即移除，名字被锁定For a suspicious account, OSN lists it in the table with an empty address: the registration is removed and the name is locked
时间Time每一版管理名表在它上链的区块高度生效，所有节点同时切换，历史全部保留Each table version takes effect at its block height; all nodes switch together and the full history is kept

对不同的人意味着什么What it means for you

OSN 员工OSN staff

用钱包注册自己的 .osn 名字，再由管理员加入邮箱等系统的白名单。登录时用钱包签名，不需要密码。Register your .osn name with your wallet; an admin adds you to the mail and other whitelists. You sign in with a wallet signature, no password.

合作伙伴与客户Partners and clients

看到一个 .osn 名字时，请通过 OSN 官方渠道确认对方是否为 OSN 员工。名字本身只证明「这个名字属于这个钱包」。When you see a .osn name, confirm through official OSN channels that the person works for OSN. The name itself only proves "this name belongs to this wallet".

外部注册者Outside registrants

可以注册 .osn 名字，但无法使用 OSN 的任何系统；冒用将被冻结。You may register a .osn name, but cannot use any OSN system; misuse will be frozen.
